# BR MOD 3 — отчёт по реализации и проверке

Дата проверки: 2026-08-27. Окружение: личный телефон владельца и его тестовый
сервер AZURE. Этот отчёт не содержит учётных данных.

## Архитектура

```text
App.<clinit> -> libgadget.so -> cheat.js -> hot-reload payload.js
App.onCreate -> br.mod.BrMenu -> WindowManager overlay -> br_cfg.txt

payload-core-v3.js
  |- clock_gettime hook (только вызовы из libblackrussia-client.so)
  |- multiTouchEvent hook и synthetic input
  |- нативные toggleDrawing2dStuff / toggleBloor
  |- eglSwapBuffers FPS counter
  |- read-only координаты локального player/vehicle wrapper
  `- read-only send/sendto diagnostics при DEBUG=ON
```

Активный `payload.js` на телефоне совпадает с локальным
`payload-core-v3.js` по SHA-256:

`9d334ccea8b1ad59839d0bddc53b247af242f834d7d398a4ea9f2ca935d428ab`

## Реализованные функции

### SPEED x1 / x1.5 / x2 / x3

Масштабируется монотонное время только для вызовов из игрового native-модуля.
При x1.5, x2 и x3 горизонтальный ввод джойстика автоматически смягчается
нелинейной кривой. Минимальный коэффициент соответственно 0.70, 0.50 и 0.34;
полное отклонение джойстика сохраняется. Отдельного переключателя STEERING нет.

### AUTO RUN

Удерживает основной виртуальный джойстик вперёд через штатный JNI
`multiTouchEvent`. При выключении обязательно отправляет release. После
перезапуска всегда принудительно OFF, даже если предыдущая сессия оборвалась.

### ANTI AFK

После 30 секунд без реального касания отправляет короткий безопасный импульс
джойстика и повторяет его не чаще раза в 30 секунд. При активном AUTO RUN не
мешает удерживаемому вводу.

### GAME HUD

Вызывает реальную нативную функцию `toggleDrawing2dStuff`. Управляет всем
стандартным 2D-интерфейсом игры; инверсия её JNI-аргумента учтена в ядре.

### BLUR FX

Вызывает реальную нативную функцию `toggleBloor`. Эффект проверен визуально.

### INFO HUD

Отдельный неперехватывающий касания overlay показывает FPS, режим on-foot или
vehicle, XYZ, скорость, auto-run и anti-AFK. Координаты читаются локально и не
изменяются.

### DEBUG LOG

Записывает раз в 5 секунд число масштабированных clock-вызовов, касаний,
сглаженных движений и наблюдаемых пакетов 76/81 байт. Сетевой observer только
читает данные и ничего не переписывает.

### SCREEN AWAKE и RESET ALL

SCREEN AWAKE использует Android `View.setKeepScreenOn`. RESET ALL возвращает
безопасный профиль: x1, auto-run OFF, anti-AFK OFF, game HUD ON, blur OFF,
info HUD OFF, debug OFF, screen awake ON.

## Автоматическая проверка

- APK скомпилирован Java 8 / D8, выровнен и подписан совпадающим сертификатом.
- Подпись APK: Android Debug, SHA-256 сертификата
  `1683f2fa178a634127d38e492674caf048806036dd262894bc7d0dee6a262fd7`.
- SHA-256 `br-mod-v3.apk`:
  `f0488683cddac9772a50b1e5a69ac7a7ceffd6ce93b583b8a7f811497771769d`.
- `payload-core-v3.js` проходит `node --check`.
- Игра после in-place обновления осталась подключённой к серверу без падения.
- FPS observer показывал живые значения примерно 56–99 FPS.
- Локальная позиция стабильно читалась в состоянии ON FOOT.
- SPEED x1.5 применился; debug зарегистрировал `scaled5s=325` в коротком тесте.
- Автосглаживание зарегистрировало `smooth5s=84` при `touch5s=86`.
- AUTO RUN реально переместил персонажа примерно на 3.8 м за тест и после OFF
  позиция стабилизировалась; в логе есть start/stop hold.
- ANTI AFK выполнил два 30-секундных pulse, процесс игры остался жив.
- GAME HUD OFF визуально убрал стандартный игровой UI и ON восстановил его.
- BLUR FX ON/OFF визуально применился и сбросился.
- INFO HUD отображал и обновлял FPS/XYZ поверх игры.
- RESET ALL вернул все безопасные значения; они сохранились после контрольного
  перезапуска. Финальный активный профиль — безопасный.

## Намеренно не добавлено

- Прямая запись XYZ была отдельно проверена: сервер/физика возвращает исходную
  позицию. Поэтому кнопки TELEPORT/SAVE POS/RETURN не добавлены как ложные.
- Экспорт `setDebugMenuVisible` в этой сборке является пустой заглушкой; вместо
  него реализована собственная диагностика.
- Бессмертие, wallhack и no-fall не добавлены без стабильной подтверждённой
  точки в текущем клиенте/сервере: декоративные кнопки или рискованные патчи в
  финальную сборку не включались.

## Ручной чек-лист владельца

1. Нажать `[BR3]`; SPEED последовательно переключить x1.5, x2, x3 и x1.
2. На x3 проверить бег и машину: мелкий поворот должен быть мягче, полный ход
   джойстика должен оставаться доступным.
3. AUTO RUN включить на свободной площадке и выключить; после OFF персонаж не
   должен продолжать идти.
4. ANTI AFK включить и оставить без касаний минимум на 35 секунд.
5. Проверить GAME HUD, BLUR FX и INFO HUD.
6. DEBUG LOG включать только при диагностике, затем выключить.
7. В конце нажать RESET ALL.
