# BR MOD 5 — полный разбор функций

Дата: 2026-08-28. Контекст: личный телефон владельца, приватный тестовый сервер.
Учётные данные не записаны. APK автоматически на телефон не устанавливался.

## Градации

- **Лёгкая** — локальный переключатель/интерфейс либо уже известный объект игрока.
- **Средняя** — нужен точный engine hook/поле и один контролируемый runtime-тест.
- **Сложная** — несколько подсистем, серверная коррекция или инвентарь.
- **Практически невозможная client-only** — итоговое состояние решает сервер.
- **Исключена** — воздействует на других игроков/чужое имущество либо имитирует администратора.

## Photon: найденная архитектура

- `libPhoton.so` регистрирует 41 собственный ARM64 hook через Dobby/A64HookFunction.
- Hook `libPhoton.so + 0xc8b4b4` при включённом флаге временно умножает float
  аргумента `x1 + 0x0c` на `4.5`, вызывает оригинал, затем восстанавливает значение.
- Это подтверждает точечный speed mechanism Photon и ошибку v3 с общим временем.
- Адреса старых игровых функций Photon получает в runtime-таблице `.bss`; старые
  смещения нельзя напрямую применять к текущему клиенту 16.98.
- Для настоящих Immortality/No Freeze/No Recoil нужен dump этой runtime-таблицы,
  затем сигнатурное сопоставление старой и текущей функций.
