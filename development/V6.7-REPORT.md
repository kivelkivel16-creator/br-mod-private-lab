# BR MOD v6.7 — локальная физика

Дата: 2026-08-29. Область: выбранный локальный персонаж и текущий транспорт на
личном тестовом сервере. Сетевые хуки и обход античита отсутствуют.

## Изменения

- Транспорт: ускорение за тик увеличено примерно в 1,5 раза; пределы
  горизонтальной скорости `0.53 / 0.58 / 0.63` для `x1.5 / x2 / x3`.
- Персонаж: подтверждённое поле линейной скорости `+0x168/+0x16c/+0x170`;
  пределы подняты до `0.20 / 0.28 / 0.36`.
- Прыжок: множители импульса `2.2 / 2.8 / 3.5`, пределы вертикального импульса
  `0.48 / 0.66 / 0.86`.
- Ходьба под водой: начальная высота фиксируется на `1.25` ниже положения в
  момент включения, а не на поверхности. Урон от воды не меняется.
- Полёт: прежняя фиксация высоты удалена. Направление читается из
  `Scene.camera -> rw::Camera.Frame.matrix.at`; движение идёт по полному
  вектору камеры, включая вверх/вниз. Удержание левого джойстика — движение,
  отпускание — зависание. Скорости `0.18 / 0.24 / 0.32 / 0.44` для
  `x1 / x1.5 / x2 / x3`.

## Подтверждённые адреса текущей сборки

- Указатель локальной сущности: holder `base+0x19d9920`, pool
  `base+0x2b2f120`, stride `0xf8`.
- Текущий транспорт: wrapper `+0x500`, флаг `+0x508`.
- Координаты: `+0x38/+0x3c/+0x40`.
- Линейная скорость: `+0x168/+0x16c/+0x170`.
- Scene pointer slot: `base+0x19d9c58`; camera `Scene+0x8`; frame
  `Camera+0x8`; camera forward vector `Frame+0x50/+0x54/+0x58`.

## Не реализовано клиентским патчем

- Бесконечная стамина и отключение урона/утопления: серверные тестовые правила.
- Принудительное воздействие на других игроков или чужой транспорт.
- Подавление серверной коррекции и обход античита.
